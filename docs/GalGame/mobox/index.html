    mobox简介

    下载与安装

    Termux, Termux-X11, lnput Bridge 点击下载三个安装软件(可能需要代理), 点击前往我站分流 安装完成后打开Termux输入

    需要开启全局代理或者自行搜索termux走代理软件的http代理, 反代无法解决安转的网络问题

    Bash自动 · 3 行展开代码收起代码

    然后选2安装mobox wow64 输入mobox选1启动等待初始化完成 返回Termux输入1回车关闭

    配置

    Termux-X11

    配置如图即可, 你也可以自行翻译修改

    Termux/mobox

    打开Termux输入mobox 这里的选项可以手点击可

    1. 分辨率设置选2>4>1, 2560x1600(根据需要设置即可)

    更改语言和添加字体(根据需要添加) 有点小bug导致汉化不完全不过不影响使用 mobox设置中文选2>4>3, 输入zh_CN 输入

    然后输入

    JavaScript自动 · 1 行展开代码收起代码

    添加或更改盘符对应的实际路径 cd /data/data/com.termux/files/usr/glibc/wine-9.3-vanilla-wow64/.wine/dosdevices 该文件夹下存储着你的mobox硬盘(wine版本可能不同根据实际来) 举个栗子: 输入ls即可看到硬盘, 使用rm e:删除E盘, 输入ln -s /storage/emulated/0/ExaGear e:将ExaGear添加为E盘, 使用ls e:可以查看硬盘路径是否正确

    Input Bridge

    1. 打开后给予上层显示权限

    2. 点+号新建配置

    3. Language选择中文

    4. 点手指图标选编辑控件根据需要添加按键(左边那个框可以点中间进行拖动)

    5. 创建完成后点出口

    6. 回到主页选择根文件夹(保存目录可自行修改)

    7. 将安装程序复制到"下载"

    开始使用

    1. 退出Input Bridge, 重新打开后挂在后台

    2. 打开Termux输入mobox启动

    3. 找到你Input Bridge的保存目录, 进入IputBridge/INstaller双击install.bat, 右上角看到齿轮图标意味着成功开启了虚拟键盘.

    4. 最后启动游戏开始游玩!

    PS

    • 虚拟键盘点击设置, 点击小眼睛可关闭虚拟键盘

    • 虚拟键盘按钮类型里叉=方向键, 戳=摇杆, 按钮的自定义文本需要更改形状来刷新, 关键代码才是决定该按键输出什么键

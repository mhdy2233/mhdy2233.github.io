qq缓存相关

D:\QQ信息保存的文件夹\qq号\nt_qq 这个nt_qq文件下是你的缓存目录里面保存了所有的图片、emoji、消息等..占用了大量的空间，并且是自动缓存的，不管你看没看到都缓存！而且缓存后不会删除，会缓存两份，如果你再下载则是3份。如果确定不使用则可以直接删除，注意保存重要数据！

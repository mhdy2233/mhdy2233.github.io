git详细安装步骤




Git 2.25.0 安装步骤：


进入Git官网[Git官网](https://git-scm.com/)，点击 Downloads 下载：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-2b31d71e0a1f88ac25aa580094602d8a_720w.webp)



选择你的系统类型，我的是 Windows：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-27d1caaa40faeafaf23e8e087948b02a_720w.webp)



应该会直接弹出下载：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-28c8d91e603ccc8e491e68459f152381_720w.jpeg)



如果没弹出的话，选择适合你的系统的即可，如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-910eda78b2932aadb839cc07d7900fa7_720w.webp)



下载完成双击打开：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-ffd6a780ac8b9f7f7e66604f1c796f99_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-df7dfe1d55e72e2f28292733194ed1f2_720w.webp)



可以选择 Git 安装位置，然后点击 ***next***：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-acdb676bf346b7bc844946ba5b4994d2_720w.webp)



保持默认就好，直接点击 next：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-01beee7ec450d746190901e14896f183_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-6f8213444c1d382a9f72c012b43cf9f4_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-3dcca92f4b2ab2a909e773c75d55bb9e_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-99ba29abf274903ac4319558920d5741_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-09bafa50241530e08ea6ca7a215de2dd_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-a5179b18ef6e7ee2373278803d07eeb5_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-51a46602b6b59bf66447a47ea1117232_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-b63d3a8617a7c9d2574c8eb5ed98d217_720w.webp)



完成后选择打开 Git Bash 即可：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-c4f1129c5fbb5ed081e6817d1bb3b97d_720w.webp)

![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-f9c4facc5feccfd6613965fabc8d0833_720w.webp)



打开 Git Bash, 输入git:


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-3d312f3ae164edbe8627faeb25684805_720w.webp)



回车得到如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%8C%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-0f41afdb907b3f7f9b26769a2eab1784_720w.webp)



此时你的 Git 就已经安装完成啦！

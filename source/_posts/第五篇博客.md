# [](#个人博客第5篇——安装node-js和Hexo)个人博客第5篇——安装node.js和Hexo

node.js和Hexo安装教程




## [](#1-安装nodejs)1. 安装nodejs

下载地址：[node.js官网](https://nodejs.org/en/)


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-513ec2adc4a328ce83c2a4179503c05d_720w.webp)



如上图，直接点击下载，完成后双击安装，安装直接默认 next 就好，很简单，需要改的也就是安装位置改一下，我是在D盘新建了一个文件夹 nodejs，安装在这个文件夹里。如果要看详细到每一步的话，可以看一下这个文章：[node.js 安装详细步骤教程](https://blog.csdn.net/antma/article/details/86104068)。


安装完成可以用打开cmd检验一下是否安装成功，用 node -v 和 npm -v 命令检查版本，如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-6b7a4812c7136797111e4e3cff46d91a_720w.jpeg)



### [](#设置npm在安装全局模块时的路径和环境变量)设置npm在安装全局模块时的路径和环境变量

因为如果不设置的话，安装模块的时候就会把模块装到C盘，占用C盘的空间，并且有可能安装好hexo后却无法使用，所以我们需要设置一下：


在 nodejs 文件夹中新建两个空文件夹 node_cache、node_global，如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-29f016d553ed391fd5a7d447b8347706_720w.webp)



打开cmd，输入如下两个命令：


1
2
npm config set prefix &quot;D:\nodejs\node_global&quot;
npm config set cache &quot;D:\nodejs\node_cache&quot;



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-46234877dbb7978d7935e3512a5fd8dc_720w.webp)



设置环境变量：win10系统 –&gt; 打开控制面板 –&gt; 系统 –&gt;高级系统设置 –&gt; 环境变量 ，然后在系统变量中新建一个变量名为“NODE_PATH”，值为“D:\nodejs\node_global\node_modules”，如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-32e082000b954265c1a00e17918dea5c_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-a9a898db5d88f3a11f1b1c390d4dcced_720w.webp)



然后编辑用户变量里的Path，将相应npm的路径改为：D:\nodejs\node_global，如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-c74349d22c77b1e6add874bd27ab6a3b_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-ac8d2c68b356f2dfcfcf051b58a1c71f_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-6747c5c280f7d53565e60b6cb1c761be_720w.webp)



### [](#测试)测试

在 cmd 命令下执行 npm install webpack -g ：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-d00cd21a722a0b861bfc30293ae6fcbb_720w.webp)



然后 webpack 这个模块已经在我们设置默认的文件夹中了：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-2b8ee5f8f53ab2db8fc6f9739e481de9_720w.webp)



## [](#2-安装Hexo)2. 安装Hexo

Hexo就是我们的个人博客网站的框架，在安装之前，我们要先在GitHub上创立一个仓库，如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-010e684d021680e94f0142adc3e014b8_720w.webp)



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-d6fa95cce4e455153187135c8ee12359_720w.webp)



点击 settings 设置：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-39e664f7edf18ee56795a8c96f669424_720w.webp)



滑到页面底端，出现如下图所示就说明已经成功了：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-6a000b836ae32c3d118c1fdeb4696f1c_720w.webp)



接下来就是安装Hexo，首先在D盘建立一个文件夹 Blog，点开 Blog 文件夹，鼠标右键打开 Git Bush Here，输入npm命令安装Hexo：


1
npm install -g hexo-cli



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-7b36dbcaf294d16ebcbf46888ff4ff5d_720w.webp)



安装完成后，输入 hexo init 命令初始化博客：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-e58d83d78710849cdc32321f122550e8_720w.webp)



然后输入 hexo g 静态部署：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-fdc87aa8600fdbbecdc0c9bc2c141412_720w.webp)



这时网页已经部署完成，输入 hexo s 命令可以查看：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-11a0b4917c962bab07a48f7a04160e8b_720w.png)



浏览器输入 [http://localhost:4000](http://localhost:4000/) 就可以打开新部署的网页：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-5a8d3a94b1eb5e4e79f2e733ddaed2aa_720w.webp)



看完之后 ctrl +c 停止运行服务器。


### [](#将Hexo部署到GitHub)将Hexo部署到GitHub

现在回到我们的 Blog 文件夹，用笔记本打开 _config.yml 文件，如下图：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-b60225e9260cd78e1142e81c133b567a_720w.webp)



下滑到文件底部，填上如下内容：


1
2
3
4
deploy:
  type: git
  repository: https://github.com/fengye97/fengye97.github.io.git  #你的仓库地址
  branch: master


注意空格：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-7f9e09b1827fd9202088cc9d9b19880e_720w.png)



你的仓库地址就是下图这个：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-5014abdff592085ca394335730020fae_720w.webp)



然后回到 Blog 文件夹中，打开 Git Bash，安装Git部署插件，输入命令：


1
npm install hexo-deployer-git --save



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-a5172536904c8eaa602debc6e54c877b_720w.webp)



然后分别输入以下三条命令：


1
2
3
hexo clean   #清除缓存文件 db.json 和已生成的静态文件 public
hexo g       #生成网站静态文件到默认设置的 public 文件夹(hexo generate 的缩写)
hexo d       #自动生成网站静态文件，并部署到设定的仓库(hexo deploy 的缩写)



![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-54e0b045f1d46c70e740ec83a3552fe0_720w.webp)



完成以后，打开浏览器，输入 [https://xxx.github.io](https://link.zhihu.com/?target=https://fengye97.github.io/) 就可以打开你的网页了：


![](/2023/09/23/%E7%AC%AC%E4%BA%94%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-aa3a0b56dbcadf942397b8ea224b78b9_720w.webp)



现在虽然可以访问我们的网站，但是网址是GitHub提供的：[http://xxxx.github.io](https://link.zhihu.com/?target=http://xxxx.github.io) 而我们想使用我们自己的个性化域名，这就需要绑定我们自己的域名。下一篇介绍解析域名和绑定域名。

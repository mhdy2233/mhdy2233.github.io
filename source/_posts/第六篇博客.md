# [](#个人博客第6篇——解析域名)个人博客第6篇——解析域名

域名需自行购买看第四篇




## [](#解析域名)解析域名

第一步：登录[万网](https://link.zhihu.com/?target=https://wanwang.aliyun.com/)，点击控制台，在你已购买的域名后点击解析添加两条解析记录：


![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-dfe2e69910f62b27dcd638a121b3e87d_720w.png)



![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-09e6f42649e43d667f97042fac168e38_720w.png)



那个IPV4地址可以通过ping得到，具体方法是：打开cmd输入下面命令：


1
ping fengye97.github.io    #ping + 你的GitHub的网址



![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-a55fc3c79e88a0648cbde43c0ed91ad3_720w.webp)



第二步：打开 Blog 文件夹里的 source 文件夹，添加CNAME文件，可以先创建一个CNAME.txt文件，打开后写上你的域名，不要加www否则每次访问都必须加www，但如果不带有www，以后访问的时候带不带www都可以访问，保存后记得要重命名，将.txt删除，如下图：


![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-baa37d179051eebab009eee4d4b4c3d1_720w.webp)



![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-dc6b077f1a2ababc47ef1cb3f9d29277_720w.webp)



第三步回到 Blog 文件夹，右键打开 Git Bash，依次输入下面三条命令：


1
2
3
hexo clean
hexo g
hexo d


打开GitHub，看看CNAME文件是否已经在你的项目中，点击 *settings ：*


![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-794b60703c12493db0af6e3bee662fdb_720w.webp)



查看你的网址是否已保存：


![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-1d143d2af3271ec95ce5aeec8cc6ded0_720w.webp)



如果是空白的看看能不能自己填上去，我的 *save* 键一直是灰白的不能点击，但我的CNAME文件传上去了之后就自动填上了。如果你没有CNAME文件，可以自己添加，方法如下：


![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-3302636f22b32bc651fc3413a033cf3e_720w.webp)



![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-513827098b83b5517cb1cbf2778f7828_720w.webp)



![](/2023/09/23/%E7%AC%AC%E5%85%AD%E7%AF%87%E5%8D%9A%E5%AE%A2/v2-85b812b5bb5c2390b4fa30ccf403d0b4_720w.webp)



这样就完成啦！这时候你就可以浏览器直接输入你的域名就会进入你搭建的网页啦！
